# Web Design Practice

An HTML and CSS web-design practice site with home, about and services pages. Forms are visual examples and do not send messages.

[Live demo](https://marvericklnk.github.io/Sample-8/)

![Project screenshot](screenshots/preview.jpg)

## Run locally

Download the code and open `Sample-8/index.html` in your browser. You can also open the folder in VS Code and use Live Server.
